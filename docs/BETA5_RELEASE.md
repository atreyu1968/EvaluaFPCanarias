# EvalúaFP Canarias 1.2.10-AG-CN-beta.5

Versión preliminar para evaluación y pruebas, no una edición definitiva. Incorpora el código auditado en la integración n.º 1: currículo de A&G en Canarias, ámbitos comunes de GB, recuperación, expediente, decisiones académicas orientativas, planes FEOE, cuaderno RA/CE, cierre docente trazable, plantillas CSV sin ambigüedad, exportaciones Additio, modo guiado y avanzado, copias verificadas y recuperación aislada.

## Descargas
Paquetes exclusivos de Windows x64, Linux x64, macOS Intel y macOS Apple Silicon. Cada paquete incluye una huella SHA-256. Extraer el archivo completo y seguir el manual de la plataforma. El código no está firmado comercialmente ni notarizado. Las pruebas de arranque automatizadas no equivalen a una validación gráfica o pedagógica en equipos reales. Usar primero datos ficticios.

## Datos existentes
Hacer copia externa antes de actualizar. No reemplazar la carpeta de datos ni ejecutar desde un ZIP. No copiar credenciales sin protección. El sistema de copias no cifra los datos académicos. Los documentos oficiales, la normativa vigente y las decisiones del equipo docente prevalecen sobre los cálculos orientativos.

## Cambios respecto a beta.4
- Versión interna diferenciada y publicación permanente con controles previos.
- Cuaderno simplificado, manejo de ámbitos comunes y navegación avanzada.
- Copias verificadas y recuperación gráfica sin activación automática.
- Cierres vinculados a evidencia revisada de FEOE.
- Manuales de las tres plataformas y guía didáctica específica.
- Compilación nativa y autoprueba aislada para cada arquitectura.
